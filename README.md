# Komorebi Table 予約サイト

空席確認、メニュー表示、予約フォーム、予約キャンセルまで動く飲食店予約サイトの静的デモです。

## 機能

- 日付ごとの空席確認
- 空席時間をクリックしてフォームへ反映
- 人数に応じた残席チェック
- 予約保存で残席数を更新
- 予約一覧表示
- 予約キャンセルで残席数を復元
- `localStorage` への保存と初期化

## ファイル

- `index.html`: 画面構造
- `styles.css`: レイアウトとデザイン
- `app.js`: 予約ロジック、空席計算、保存、キャンセル

GitHub Pagesでそのまま動作します。
